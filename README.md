# blog-website
A passion-project where I want to test my ability to create an entire end-to-end React application using zero AI. This website will be a platform to write articles and blog posts one games and media I am particularly passionate about.

# Roadmap/Ideas
- I want to make a full-on custom article creator in react, allowing the user to add seconds to their article, consisting of various elements including text and images.
- The app will then store the contents of each article in a database.
- There will be an "export as html" option.
- My website will then be built around this, displaying articles I make in categories I define, most likely by franchise. Each article will belong to a parent category.
